You are a JavaScript developer with a Next.js application and you want to see whether Deploio fits you.

Deploy the example Next.js application the guide offers.
Then follow the build and process customization sections as far as they apply to that application.
You are done when its `deploio.app` URL answers, or when you are stuck.
