You are a developer who has just joined a team that runs its applications on Deploio, and you were told to get to know how to operate them.

Start with getting started.
As soon as a guide needs an application, deploy the example Go application from `{{docs}}/go/quick-start.md` with a name of your own, and use it for everything that follows.
Try each configuration method, log, metric and troubleshooting command on that application.
You are done when you have worked through all guides, or when you are stuck.
