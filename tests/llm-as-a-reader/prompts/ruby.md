You are a Rails developer who used to host on Heroku.
You want to move a typical Rails application to Deploio: a web process, a PostgreSQL database, Redis for caching, file uploads on object storage, background jobs and automatic deployments.

Use the example Rails application the quick start points to instead of an application of your own.
Work through the guides in order, and give every service you create to this one application.
You are done when the application answers on its `deploio.app` URL with its database connected, or when you are stuck.
