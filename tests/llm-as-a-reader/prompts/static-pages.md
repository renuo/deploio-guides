You are a frontend developer with a small marketing site and a documentation site built with a static site generator.
You want both online, and you have never used Deploio.

Deploy the example sites the quick start offers.
Then read the static site generators guide as someone whose own site is built with VitePress, and do what it says as far as possible without a repository of your own.
You are done when the example sites answer on their `deploio.app` URLs, or when you are stuck.
